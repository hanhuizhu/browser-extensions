# 暗黑皮肤

给所有网页自动套上暗黑皮肤。无 AI、无网络请求，所有设置存本机。

## 功能

- **自动暗黑**：content script 在 `document_start` 注入，整页 `invert + hue-rotate` 反色，图片/视频/iframe 再反转回来保持原样
- **URL 排除列表**：支持 `*` 通配符，如 `*tuhu*` 匹配 URL 中含 tuhu 的所有页面；不写 `*` 按子串匹配。弹窗里也可以一键「排除当前站点」
- **暗度可调**：80% ~ 100% 滑杆，控制反色强度（越高越黑、对比越强）
- **底色可调**：色板选暗黑底色（插件会先做一次反色再注入，抵消整页反色滤镜，最终呈现你选的颜色）
- 所有调整**实时生效**，无需刷新页面（content script 监听 `storage.onChanged`）

## 使用

安装即全局生效。点击插件图标：开关 / 调暗度 / 换底色 / 排除当前站点；点 ⚙ 管理完整排除列表。

## 说明

- 反色方案对本来就是深色的网站会变亮，把这类站点加进排除列表即可
- 饱和度高的底色经过色相旋转会略有偏差，建议选接近灰黑的颜色
