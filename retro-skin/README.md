# 网页时光机

一键把当前网页变成复古风格，纯 CSS 注入，无 AI、无网络请求，随时恢复。

## 主题

- 💻 **终端绿字**：黑底荧光绿 + 等宽字体 + 扫描线，图片做绿色调滤镜
- 🪟 **Win98**：经典灰 + 藏青标题栏 + outset/inset 立体边框
- 👾 **像素风**：图片像素化渲染 + 等宽字 + 硬阴影

## 使用

点击插件图标 → 选主题；「恢复原状」或刷新页面即还原。皮肤只对当前标签页生效，各标签页互不影响。

## 说明

- 用 `chrome.scripting.insertCSS/removeCSS` 实现，不改动页面 DOM
- 各标签页当前皮肤状态记在 `chrome.storage.session`，关浏览器自动清空
- 想调整或新增主题：改 `constants.js` 里的 `THEMES` 即可
