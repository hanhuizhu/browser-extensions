# 浏览时间账本

统计各网站的浏览时长，一键生成 AI 点评的「本周注意力去哪了」报告。底层调用 DeepSeek API。

## 功能

- 每分钟采样一次：用户不空闲（60 秒内有键鼠操作）且 Chrome 在前台时，给当前活跃标签页的站点记 1 分钟
- 弹窗查看「今日 / 近 7 天」各站点时长排行（条形图），数据保留 30 天
- 「AI 周报点评」：把近 7 天数据发给 DeepSeek，生成犀利但善意的注意力点评：整体画像 / 最大时间黑洞 / 值得表扬的 / 一条建议
- 数据全部存本机 `chrome.storage.local`，除了你主动点周报，不会外发任何浏览记录

## 使用

安装后自动开始统计，逛一会儿后点击插件图标查看。AI 周报需在设置页（⚙）填 DeepSeek API Key。

## 说明

- 采样粒度 1 分钟，数据是近似值，适合看趋势不适合精确计时
- 挂机不动（空闲超 60 秒）、Chrome 切到后台都不计时，避免虚高
