# 接口解说员

捕获当前页面的 XHR/Fetch 请求，一键让 AI 解说每个接口大概在干嘛。逆向理解别人网站的实现、快速熟悉陌生系统时使用。底层调用 DeepSeek API。

## 功能

- 后台用 `webRequest` 按标签页记录 XHR/Fetch 请求（页面导航自动重置，标签页关闭自动清理，数据存 `chrome.storage.session`，关浏览器即消失）
- 弹窗按「方法 + 路径」去重聚合展示：方法徽标、调用次数、状态码（4xx/5xx 标红）
- 「AI 解说」：把接口清单（含查询参数名）发给 DeepSeek，输出整体架构判断、主要接口用途推测、埋点/监控类杂音识别
- 每个标签页最多记录 300 条（`constants.js` 中 `MAX_LOG_SIZE` 可调）

## 使用

安装后**先刷新一次页面**开始记录，操作一会儿页面后点击插件图标 → AI 解说。首次使用需在设置页（⚙）填 DeepSeek API Key。

## 说明

- 只能拿到请求的 URL/方法/状态码，拿不到请求响应体（webRequest 的限制），解说基于路径语义推断
- 本插件自身对 DeepSeek 的请求已排除，不会出现在列表里
